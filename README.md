# Drawers - Chrome Extension

A powerful bookmarking and resource organization tool designed for educators, researchers, and knowledge workers who need more than traditional browser bookmarks.

## 📦 Installation Instructions

### Step 1: Download the Extension

1. **Download the extension folder** from Google Drive:
   - Visit: [https://drive.google.com/drive/folders/1f3Dh7sDV4UNlOOgJWpt7D_p6eJn6jnZ2?usp=drive_link](https://drive.google.com/drive/folders/1f3Dh7sDV4UNlOOgJWpt7D_p6eJn6jnZ2?usp=drive_link)
   - Click the **"Download"** button (or right-click the folder and select "Download")
   - The folder will download as a `.zip` file

2. **Extract the downloaded folder**:
   - Locate the downloaded `.zip` file (usually in your Downloads folder)
   - **Windows**: Right-click the file and select "Extract All..."
   - **Mac**: Double-click the `.zip` file to extract it
   - Move the extracted `Drawers` folder to your **Desktop** (or another permanent location you won't accidentally delete)

### Step 2: Load the Extension in Chrome

1. **Open Chrome Extensions page**:
   - Open Google Chrome
   - In the address bar, type: `chrome://extensions/` and press Enter
   - OR click the three dots (⋮) in the top-right → **More tools** → **Extensions**

2. **Enable Developer Mode**:
   - Look for the **"Developer mode"** toggle in the top-right corner
   - Click the toggle to turn it **ON** (it should turn blue)

3. **Load the extension**:
   - Click the **"Load unpacked"** button (appears after enabling Developer mode)
   - Navigate to where you saved the `Drawers` folder (e.g., Desktop)
   - Select the **`Drawers`** folder and click **"Select Folder"** (or **"Open"** on Mac)

4. **Verify installation**:
   - You should see the Drawers extension appear in your extensions list
   - The extension icon should appear in your Chrome toolbar (top-right, near the address bar)
   - If you don't see the icon, click the puzzle piece icon (🧩) and pin Drawers

### Step 3: Start Using Drawers

1. **Click the Drawers icon** in your Chrome toolbar
2. Click **"+ Add Drawer"** to create your first drawer
3. Name your drawer (e.g., "Research Papers", "Teaching Resources", "Project Links")
4. Start adding cards with links, descriptions, and tags!

## 🚀 Key Features

- **📂 Organized Drawers**: Group resources by project, course, or topic
- **📝 Rich Context**: Add titles, descriptions, and links to each card
- **🏷️ Flexible Tagging**: Create custom tags and filter cards instantly
- **🔍 Powerful Search**: Search across all drawers and cards, including archived content
- **📤 Easy Sharing**: Export drawers as `.drawer` files to share with colleagues
- **📦 Archive**: Archive old drawers to keep your workspace clean

## ⚙️ Troubleshooting

### Extension doesn't appear after loading
- Make sure you selected the **`Drawers` folder itself**, not a parent folder or a file inside it
- The folder should contain `manifest.json`, `popup.html`, `popup.js`, and `popup.css`
- Try refreshing the extensions page (chrome://extensions/) and reloading the extension

### Extension shows errors
- Make sure you extracted the entire folder from the `.zip` file
- Verify that all files are present in the folder
- Try removing the extension and re-loading it

### Extension icon not visible
- Click the puzzle piece icon (🧩) in your Chrome toolbar
- Find "Drawers" in the list and click the pin icon to keep it visible

### Data not saving
- Make sure Chrome has permission to store data
- Check that you're not in Incognito mode (extensions may have limited functionality)

## 🔄 Updating the Extension

When a new version is released:

1. Download the new version from Google Drive (same link)
2. Extract the new folder
3. Go to `chrome://extensions/`
4. Click the refresh icon (🔄) on the Drawers extension card
5. OR remove the old version and load the new one following the installation steps above

**Note**: Your data is stored separately by Chrome and will not be lost when updating.

## 📖 Usage Tips

### Creating Effective Drawers
- Create separate drawers for different projects, courses, or topics
- Use clear, descriptive names for your drawers
- Archive old drawers instead of deleting them to preserve your work

### Organizing with Tags
- Create tags for common themes (e.g., "Important", "To Read", "Examples")
- Use consistent tag names across drawers for better organization
- Apply multiple tags to cards for flexible filtering

### Sharing Resources
- Use the **Download Drawer** option to export collections
- Share `.drawer` files with colleagues via email or shared drives
- Upload `.drawer` files from others to import their collections

### Searching Effectively
- Use the main search to find cards across all drawers (active and archived)
- Click search results to jump directly to the card in its drawer
- Archived results will prompt you to restore the drawer
